# Security policy

## Reporting a vulnerability
Report a vulnerability privately by email to famhermus@gmail.com. Do not open a public issue for it.

## What to include
- The plugin version (run `/aico:version`).
- The steps to reproduce.
- The impact you see.

## Supported version
The supported version is the release that the `stable` pointer names. Fixes ship as a new release, and that release carries a `Rollback:` line.
