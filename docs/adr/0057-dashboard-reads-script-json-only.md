# The dashboard reads only aico script JSON and binds to loopback by default

Status: proposed (Plan Gate, task 2026-11-04 01.19 - Skillset Dashboard Draft). Contracts: `docs/contracts/dashboard.md`, `docs/contracts/run-state.md` (v1.8), `docs/contracts/run-stage.md`, `docs/contracts/intake-record.md`, `docs/contracts/pr-links.md`, `docs/contracts/roadmap-list.md`.

The dashboard gets every fact from the JSON of aico scripts (run-state, run-stage, intake-record, roadmap-list, pr-links, `ledger.mjs report`, cost-source), plus one bounded reader of the `## Did` lines of Handoffs, and never parses a record file itself, because the spec allows data only from aico script JSON and one reader per record keeps every limit (size, links, letter case, real path) in the Module that owns the file. The server binds `127.0.0.1` unless the CEO starts it with `--lan`, never an IPv6 address, and checks the Host header, because a DNS-rebinding page could otherwise read run data. This is hard to reverse because two new record files (`stage.jsonl`, `intake.jsonl`) and the new run-state view keys become Contracts other Modules can depend on, and a page that read files directly would need its own copy of every limit.
