# Shared Playbooks pick stand-in Roles; company-type prints readable lines

Shared Playbooks (research, client, feedback, brainstorm, cooler) reach a Role only some types have through `company-type.mjs pick <role> <fallback>…`, and hand work over to the manifest's `work` Playbooks, so the script, not the Lead, decides what a type allows and `software` keeps its v0.12.0 Roles and commands; adding the missing Roles to every manifest instead would have put an architect and devops into a research consultancy. The CLI prints readable lines by default and the JSON only with `--json` (CEO form, 2026-10-27), which leaves every Playbook's `**Type:**` line unchanged. `.company/` and `project.md` are read through links again (AC7), because the value is only compared with registry keys and a link gives no power that a committed file lacks; `set` still never writes through a link.
