# Brainstorm Roles get a constant prompt and a per-round input file

The host sends the dispatch prompt before the ~13k-token Role block, so any change to the prompt rewrites that block in the cache; the format 2 prompt that carried the digest cost about four times the old byte-identical prompt in round 2 (replay, `.company/work/optimize-brainstorm/25-ai-data-engineer.md`). Format 2 therefore gives each Role one prompt that stays the same bytes for the whole run and puts everything that changes into a script-written input file at a fixed path (`.company/brainstorm-input/<run>/<role>.md`), which the Role reads first. Hard to reverse because the Playbook, the script, two Contracts and the replay numbers all assume it, and because it depends on the host's prompt order (re-check with `spike/s2-model.mjs` after a Claude Code upgrade).
