# The hand-over at 85500 is forced by hooks outside the agent, and auto compaction is blocked during a run

Status: proposed (Plan Gate, task 2026-11-02 18.32 - Context Cap Hand Over). Partly supersedes `docs/adr/0049-lead-handover-mechanism.md`: the Lead no longer hands over by compaction; its `PreCompact` and `SessionStart` hooks stay for manual `/compact` only.

A `PreToolUse` hook (`context-guard` v1) reads the context on each tool call and at 85500 denies a Step every tool but its Handoff `Write`, and for the Lead writes the Lead Handoff itself and then freezes the session, because spike runs showed models ignore notices (`tests/lead-handover/evidence.md`, run 3) while a subagent deny does fire (T1). Compaction keeps a summarised context, so it is blocked (`PreCompact` exit 2) and the next Lead starts in a new session from the records; the MCP tool `lead_new_session` (`lead-session-mcp` v1) only returns the command and starts nothing, on every OS, because no portable terminal launcher exists with Node built-ins and a spawn adds a security surface. This is hard to reverse because the Role and Lead rules, `lead-handoff` v1.7 and the setup doc all assume no compaction during a run, and the `CLAUDE_CODE_AUTO_COMPACT_WINDOW` setup is dropped.
