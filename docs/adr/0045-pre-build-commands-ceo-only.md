# Grill, to-spec and to-tickets join the CEO-only set, and a Playbook may name a command its type may lack through a gated name

The three pre-build commands shape what will be built, so they start only on the CEO's own slash command: they carry `disable-model-invocation: true`, which company-type allows only for `CEO_ONLY`, so `CEO_ONLY` grows from 7 to 10 and a hand-over to one of them is always a told command. Grill is in every company type but to-spec and feature are software only, so grill's end form names them on lines marked ``(gated: `playbooks:` lists <name>)`` and offers each only when the type lines list it, instead of weakening the naming rule for every Playbook. This is hard to reverse because the CEO-only set and the naming rule are checked by `check.mjs` and the naming test, and every later Playbook that hands over across types will copy the gated form.
