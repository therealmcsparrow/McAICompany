# The reprompt flow lives in its own always-on Playbook, not in pipeline Core

`/aico:reprompt` is a Playbook (`reprompt` v1) that runs the pipeline Setup items it needs, dispatches the `reprompter` Role with the CEO's text only as files, and owns the question round, the Use it / Edit / Keep only / Stop form and the `run-state` v1.1 `pick` record, so pipeline Core and every other request behave exactly as before. It is in the company-type `ALWAYS` list and `reprompter` is a required manifest Role (like `skill-researcher`) rather than a new always-on Role list, so every type, including later ones, gets it with no new resolution rule; the cost is that `software` is no longer exactly the v0.12.0 company (`company-type` v1.2; drafted as v1.1 before main took that number for ADR 0026, which also makes reprompt a model-startable Playbook with no `**Type:**` line).
