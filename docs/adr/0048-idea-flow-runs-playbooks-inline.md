# The idea flow runs each route step inline from its Playbook file

aico:idea and aico:bug run every route step in the same session: the Lead reads that Playbook's SKILL.md from the plugin root and follows it up to a stop point, instead of starting it with the Skill tool. Grill, to-spec and to-tickets are CEO-only Playbooks and the Skill tool refuses them (ADR 0045), and the CEO's own form pick in the flow is the start. The stop points are fixed headings (the grill Playbooks before their End form, reprompt before Show and pick, cooler before the commit, brainstorm and research before their outcome pick, to-spec and to-tickets before End, triage before its Brief Gate step), listed in skills/idea/references/routes.md, the one text both Playbooks share. A test asserts that each heading exists in its target SKILL.md, so renaming one breaks the build instead of the flow. The skill name is read from a fixed list, never from idea, grill or ticket text, and the allowed picks come from `idea-flow options`. The existing Playbooks are not edited for the flow. This is hard to undo because the route text, the test and both Playbooks now depend on those headings.
