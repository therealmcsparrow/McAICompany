# aico owns its anti-slop pass

Status: proposed (Plan Gate, task 2026-11-02 01.40 - Unslop Skill Draft)

aico drops the third-party writing clean-up skill and owns the pass itself: the writing skill holds tells and rewrite steps in its own words, a Node scanner with no dependency and no network reports tells but never rewrites a file or fails a ship, and a voice profile of style features only is learned fresh each run from the shipped docs and README. An outside skill was uneven and could not be tested or told the product's voice, and the CEO ships this prose under their own name. This is hard to reverse because the writing Roles, setup and the skill manifest then rely on the own pass, and setup offers to remove the old skill from existing installs.
