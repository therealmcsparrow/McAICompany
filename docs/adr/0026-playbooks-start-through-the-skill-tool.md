# Playbooks start through the Skill tool; seven commands stay CEO-only

Hand-overs between Playbooks (brainstorm → research or the type's `work` Playbook, research → `work` or brainstorm, lead and triage routing, refactor → audit) dead-ended because the Skill tool refuses a skill with `disable-model-invocation: true`, so every Playbook drops that flag except `help`, `version`, `language`, `settings`, `setup`, `skillspector` and `pentest`, which no hand-over needs and which write config, install software or attack a target; a Playbook is now recognised by its `argument-hint:` frontmatter, not by the flag (CEO, Plan Gate form 2026-10-27). What stops an unasked start is now text, not the harness (a guard sentence first in every visible Playbook's description, the Lead's "Starting a Playbook" rule, an `aico:handoff` line that Roles never start one, and the Gates every acting Playbook already has), so this is recorded as an exception to `cc.S2` and a spike checks whether Roles can be denied the Skill tool per skill.
