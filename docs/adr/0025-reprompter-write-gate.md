# The reprompter's tool calls pass an allow-list gate, and the checker refuses to run without it

The reprompter reads text the CEO pasted, so a steered reprompter could write anywhere an auto-accepted Write reaches (ignored folders, `~/.claude.json`, auto-memory, git config); two review rounds showed that a watch list of dangerous places always misses the next one. So the aico hooks module gets an always-on `tool.check` gate that allows a recorded reprompter exactly two Write targets, a short Read list and the `aico:handoff` skill, and denies everything else; its `agent.spawn` hook arms the run (`reprompt-check.mjs arm` writes `.gate-<NN>`) and `reply` refuses a reply without that marker, so a session without the hooks module cannot run reprompt at all. This is hard to reverse because reprompt now depends on the function-hooks API and `$.process` (no hooks or no `$.process` means no reprompt), and the tree check is demoted to a backstop that the Contract no longer treats as the control.
