# ADR 0078: A CEO answer is recorded by a hook from the CEO's own reply

Date: 2026-11-17. Status: proposed (feature run P20261117.000001/01-feature). Contracts: `docs/contracts/lead-relay.md` v1, `run-state` v3.1.

A subagent Lead cannot ask the CEO, so it records the open form and ends `needs-ceo`; main asks with `AskUserQuestion`, a `PostToolUse` hook writes the answer from the tool result into `forms.jsonl` only when the questions match the record exactly, and the fresh Lead reads the answer from that record, never from its prompt (CEO D2). A Gate pass that is not `auto` is refused unless a recorded answer newer than that Gate's previous pass chose an option tagged with that result, so a Lead that drifts cannot pass a Gate the CEO did not pick. This guards against drift, not a hostile Lead: the record is shielded by a shell path-token block-list (also with `AICO_GUARDS=off`), and a command that builds the path at run time gets past it; on one OS user no record exists that an agent with a shell cannot write. Hard to reverse because every Gate and ask form in every Playbook moves to this path, and dropping the hook would make Gate passes rest on model-written text again.

Decided: proceed on Spike S1 (`.company/work/P20261117.000001/01-feature/06-spike-backend-engineer.md`, pass on (d)): the source is the main `PostToolUse` payload for `AskUserQuestion` (no `agent_id`), field `tool_response.answers`, a map from question text to the chosen label or the CEO's free text; S1 proved it through the SDK permission path, and Spike S2 checks the TUI and multi-select shapes from stored transcripts before the hook is built. Gate forms are single-select, so a Gate pass never depends on the unproven multi-select shape.

Decided: proceed on Spike S2 (`.company/work/P20261117.000001/01-feature/11-spike-backend-engineer.md`, 860 stored TUI answers): the TUI gives the same map as S1 (d) for a label and for Other text; a multi-select value is the labels joined with `", "` (once an array), so option labels hold no comma, a multi value is split on `", "`, and any non-string value writes no answer. Other text is kept only in the `forms.jsonl` answer row; logs show its length and hash. Because the harness lets a preset `tool_input.answers` answer a form without the CEO, a `PreToolUse` hook denies any `AskUserQuestion` call that carries `answers` (`cch.M-SEC8`); the answer hook reads only `tool_response.answers` and never checks `tool_input`, where a real pick also shows by `PostToolUse` (Spike S1).
