# In the crossfire debate style, the challenged author answers in the next round

The T15b replay measured one crossfire pair at 4,718 spend tokens for its two extra dispatches, 52.9% of the round-3 saving against a 10% limit (`.company/work/optimize-brainstorm/48-ai-data-engineer.md`). A fresh dispatch costs about 2,000 spend tokens however small its input, so no pair of dispatches can get under that limit. So the `crossfire` style no longer dispatches the pair: the idea's author gets the challenge as a `Challenge to you:` block in its next ideas-pass input file, and the Lead records the challenge as dissent, so it stays in the Digest if the run ends first. The live pair stays only in the opt-in `full_pass` style. This is hard to reverse because the settings meaning, two Contracts, the Playbook and the replay pass rule all assume it. Bringing the live pair back needs a host feature that continues an earlier agent (Spike S3).
