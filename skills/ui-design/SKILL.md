# UI design

**Use** `impeccable` for design direction, critique and polish; `hallmark` to keep the result from looking AI-generated (a final pass on any new screen or landing page); `frontend-ui-engineering` for building accessible components. Load only what the task needs. Installing `impeccable` at project scope is a manual step: the installer prints the command and does not run it.

**Fallback:** a clear hierarchy (one primary action per view); WCAG 2.2 AA (contrast, focus, keyboard, labels); every state designed (empty, loading, error, success); consistent spacing and type scale from Core's design tokens; copy via `aico:writing`. Desktop: follow platform conventions (menus, shortcuts, window controls) per OS.
