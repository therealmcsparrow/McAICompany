# TDD

**Use** `superpowers:test-driven-development` (or `mattpocock-skills:tdd`) if it's in your skill list.

**Fallback:** write one failing test for the behavior → run it and see it fail for the right reason → write the minimal code to pass → run it green → refactor → repeat. No production code without a test that failed first. For Contracts, test only the public interface (`aico:contracts`).

**Code comments are about the code only.** A comment explains what the code next to it does or why. Never put Handoff notes, Step or task references, Role names, Fix-round or reviewer notes, AI or agent mentions ("generated by", "Claude", "TODO for the next Step"), or company process in product code, tests or config. That belongs in `.company/` only (`aico:handoff`). New comments use the `Language:` of your dispatch unless the codebase's existing comments or Ruleset use another (`aico:handoff` Language).

**Scoped test runs.** During a Step, run only the test files that cover the files you changed, plus `node "${CLAUDE_PLUGIN_ROOT}/scripts/run.mjs" check` (or the product's check). Never start a full suite run in the background, and never one while another Role may be running one in the same tree. The Lead runs the full suite once, in the foreground, after the last review (`aico:pipeline` §6); CI runs it on the PR.

**Seams, one slice at a time** (`plan-tasks` v1.3). Test only at the task's `seams:` from the Task brief; `seams: none — <reason>` means no tests. Work in vertical slices: one behaviour from the task's `slice:` line, one failing test, run it red, minimal code to green, then the next. Never write all tests first. A test needed outside the seams goes under `## Decisions` with its reason.

**No tautological tests.** A test must fail when the behaviour breaks. Never assert on the test's own setup or fixture, never restate the code under test in the expectation, never mock the unit under test, and never assert only that a mock was called. Mock only what lies outside the seam. `aico:review` blocks such a test as `[test]`.
